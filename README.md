# COC Bot

部落冲突自动捐兵脚本，基于 Python + ADB + OpenCV。

## 功能

- 自动启动雷电模拟器
- 自动进入部落冲突游戏
- 自动切换到部落聊天页面
- 检测捐兵请求并自动捐兵（兵种 + 法术）
- 断线自动重新载入

> 目前仅支持自动捐兵功能。

## 环境要求

- Windows
- 雷电模拟器 9（内部分辨率 1920x1080）
- Python 3.x（需安装 opencv-python、numpy）

## 使用方法

1. 双击 `打开控制面板.bat` 启动控制窗口
2. 填写雷电模拟器安装目录（默认 `D:\leidian\LDPlayer9`）
3. 点击"启动捐兵脚本"开始运行
4. 点击"停止"可随时停止

## 文件说明

- `COC捐兵GUI.py` — 主脚本（tkinter GUI + 状态机 + 自动捐兵逻辑）
- `打开控制面板.bat` — 双击启动
- `截图.bat` / `截图工具.py` — 手动截图工具，用于制作模板图
- `templates/` — 模板图片目录（由用户手动截取）

## 注意事项

- 运行时模拟器窗口不需要置顶，脚本通过 ADB 截图和控制
- 卡片坐标基于 1920x1080 分辨率，其他分辨率需调整
- 模板图需要用户自己截图放入 `templates/` 目录
