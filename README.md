# COC Bot

部落冲突自动捐兵脚本，基于 Python + ADB + OpenCV。

## 功能

- 自动启动雷电模拟器
- 自动进入部落冲突游戏
- 自动切换到部落聊天页面
- 检测捐兵请求并自动捐兵（兵种 + 法术）
- 断线自动重新载入

> 目前仅支持自动捐兵功能。

## 准备工作

### 1. 下载并安装雷电模拟器 9

- 官网：https://www.ldplayer.net/
- 下载雷电模拟器 9 版本，安装后打开

### 2. 设置模拟器分辨率

1. 打开雷电模拟器设置（右侧工具栏齿轮图标）
2. 进入"显示设置"
3. 分辨率选择 **自定义**，设置为 **1920 x 1080**
4. DPI 设置为 **240**
5. 保存并重启模拟器

### 3. 在模拟器里安装部落冲突

1. 打开模拟器里的浏览器或应用商店
2. 搜索"部落冲突"（Clash of Clans）并安装
3. 打开游戏，登录你的账号，等到进入主界面

### 4. 安装 Python 依赖

确保安装了 Python 3.x，然后运行：

```
pip install opencv-python numpy
```

## 使用方法

1. 双击 `打开控制面板.bat` 启动控制窗口
2. 填写雷电模拟器安装目录（默认 `D:\leidian\LDPlayer9`）
3. 点击"启动捐兵脚本"开始运行
4. 点击"停止"可随时停止

## 文件说明

- `COC捐兵GUI.py` — 主脚本（tkinter GUI + 状态机 + 自动捐兵逻辑）
- `打开控制面板.bat` — 双击启动
- `截图.bat` / `截图工具.py` — 手动截图工具，用于制作模板图
- `templates/` — 模板图片目录

## 注意事项

- 运行时模拟器窗口不需要置顶，脚本通过 ADB 截图和控制
- 卡片坐标基于 1920x1080 分辨率，其他分辨率需调整代码中的坐标
- 模板图需要自己截图放入 `templates/` 目录，对应文件：
  - `coc_icon.png` — 模拟器桌面上的部落冲突图标
  - `chat_bubble.png` — 游戏主界面右下角的聊天气泡
  - `chat_open.png` — 聊天框打开后的返回箭头
  - `clan_tab.png` — 聊天框里的"部落"标签
  - `reinforce_btn.png` — 部落聊天里的绿色"增援"按钮
  - `donate_page.png` — 捐兵页面的"增援资源"标题
  - `reload.png` — 断线时的"重新载入游戏"按钮
